## 五、登录方式说明

小程序用**微信授权登录**（`wx.login` + 云服务 `signInWithWechat`）。

首次使用需要在 WorkBuddy 管理后台为该应用开启「小程序绑定」与微信登录开关。未绑定时：

- 页面能正常渲染、公开数据能读到
- 登录、下单、接单等需要身份的操作会失败

工程里的 `utils/cloud.js` 已写好本应用的 `endpoint` 与 `publishableKey`，**不需要你改任何配置**。

## 六、常见问题

| 现象 | 原因与处理 |
|---|---|
| 编译报「模块找不到」 | 点「工具 → 构建 npm」重新构建 |
| 登录一直失败 | 该应用未完成小程序绑定，或用的是测试号（测试号无微信登录能力） |
| 提示「未找到 app.json」 | 导入目录选错了，应选 `miniprogram` 这一层，不是它的父目录 |
| 预览二维码生成失败 | 用了测试号。测试号不支持预览，需换成自己的 AppID |
| 数据能读但不能写 | 未登录或不是服务者身份。服务者需在「接单」页提交入驻申请，等管理端审核 |
| 样片看不了画面 | 云存储的签名链接必须登录才能生成，未登录会显示「登录后观看」遮罩 |
| 发布后搜不到 | 微信搜索索引有 1–3 天延迟，先用「体验版」扫码 |
| CLI 报「服务端口已关闭」 | 执行 `node tools\enable-service-port.js` 重新开启，然后重启开发者工具 |

| 脚本 | 检查项 |

这些脚本都做过**反向验证**（故意注入错误能被抓出），改完代码跑一遍再提交。

### ⚠️ 小程序 WXML 表达式限制（写代码必记）

WXML 里**不支持**这两类写法，工具会静默渲染错误：

```html
<!-- ✗ 调用 JS 方法 -->
{{tags.indexOf(item) >= 0}}
<!-- ✗ 数组/对象字面量 -->
{{[1,2,3,4,5]}}
```

正确做法：在 JS 的 `data` 里预先算好。

```js
data: {
  ratingStars: [1, 2, 3, 4, 5],
  tagStates: { '技术专业': true }
}
```
```html
<view wx:for="{{ratingStars}}" wx:key="*this">★</view>
<view class="tag-chip {{tagStates[item] ? 'chip-on' : ''}}">…</view>
```

### 人工客服怎么用

**客户侧**
- 小程序：我的 → 在线客服
- 网页版：页脚 → 在线客服
- 首次进入自动创建会话，一个客户同时只有一个进行中的会话

**客服侧**
- 打开 `admin.html` → 左侧「客服会话」

**客服身份 = `staff` 表里的人**。用管理员账号登录后即可在后台看到客服会话页。

### 权限隔离（RLS）
- 客户只能读写**自己的**订单、评价、通知、客服会话
- 服务者能读写**与自己相关的**订单（作为服务者或客户）
- `staff` 表里的人（管理员/客服）能读全部、写全部
- 公开数据（服务、分类、轮播、已认证服务者）所有人可读
