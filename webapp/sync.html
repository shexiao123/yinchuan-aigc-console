客户端数据同步
为什么需要同步

微信小程序与网页版分属两个独立的云环境，数据默认不互通。 客户在小程序下的订单，需要在这里导入一次，管理端才能看到并处理。 网页版客户端下的订单则实时可见，无需导入。

第一步 · 在小程序里导出

用管理员账号在小程序打开「我的 → 平台后台 → 导出订单数据」，把生成的文本完整复制下来。

  1. 打开微信小程序「宁夏云辇文化科技有限公司」
  2. 进入「我的」→「平台后台」
  3. 点「导出订单数据」，得到一段 JSON 文本
  4. 复制这段文本，粘贴到下方输入框
